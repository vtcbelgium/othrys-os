# PRACTICAL CARTOON DAD — THEIA STARTER PROPERTY

**Status:** UTILITY-FIRST PROPERTY SEED — working identity only; final name/character design not locked.

## 1. Proven job

There is demonstrated demand for warm, practical "dad-style" instruction:
- tie a tie;
- shave/iron clothes;
- unclog a drain;
- use tools;
- hang a shelf;
- check oil/tire pressure;
- jump-start a car;
- basic household maintenance;
- confidence around ordinary adult tasks.

Theia may independently serve this job.

Theia must not clone "Dad, How Do I?" or any other creator's:
- name;
- character/likeness;
- scripts;
- catchphrases;
- jokes;
- episode edits;
- thumbnails;
- branding.

> **COPY THE JOB. BUILD A DIFFERENT FATHER.**

## 2. Promise

A funny, competent cartoon dad calmly shows the viewer how ordinary practical things work.

Tone:
- warm;
- encouraging;
- slightly corny;
- never condescending;
- safety-conscious;
- competent without macho posturing.

## 3. Why cartoon

Benefits:
- reusable character/IP;
- no filming location required;
- exact diagrams/cutaways;
- localization;
- repeatable production;
- easy shorts/long-form derivatives;
- privacy;
- B2B/white-label potential.

Risks:
- unsafe oversimplification;
- generic templating;
- lack of tactile realism;
- repetitive scenes.

The visual must add explanation, not only decoration.

## 4. Content pillars

A. Clothing/presentation
- tie;
- shirt ironing;
- sewing a button;
- shoe care.

B. Tools
- screwdriver bits;
- drill basics;
- stud finder;
- tape measure;
- wrench types;
- level.

C. Home
- unclog drain;
- stop a running toilet;
- reset breaker safely;
- bleed radiator where applicable;
- seal a draft;
- basic wall anchor concepts.

D. Car/basic mobility
- tire pressure;
- jump-start basics;
- oil check;
- wiper replacement;
- warning-light literacy.

E. Life competence
- reading a utility meter;
- basic emergency shutoffs;
- packing;
- basic maintenance schedule;
- how to ask a contractor useful questions.

## 5. Safety boundary

Do not automate dangerous instruction casually.

High-risk categories:
- mains electrical work;
- gas;
- structural work;
- roofing/heights;
- pressure systems;
- chemicals;
- automotive operations with severe injury risk.

For those:
- explain principles/safety;
- route to official/manual/professional help;
- avoid pretending a cartoon is sufficient certification.

Country/product differences must be stated when material.

## 6. Format system

**Helios**
- 3–8 minute complete tutorial;
- searchable evergreen video.

**Eos**
- 15–45 second single tip or "before you start";
- route to full tutorial when useful.

**Selene**
- maintenance calendars;
- recurring seasonal series;
- "things to check this month";
- saved evergreen playlists.

## 7. Production architecture

Preferred long-term:
- reusable cartoon dad rig;
- workshop/home sets;
- tool asset library;
- animated hands/cutaways;
- diagrams/arrows;
- branded caption style;
- deterministic instructional scenes.

For real-world physical nuance:
- optional licensed/generated/shot close-ups;
- manufacturer diagrams;
- photographic insert where rights permit.

## 8. Monetization optionality

Hyperion evaluates:
- platform revenue;
- disclosed tool/material affiliates;
- sponsorships;
- printable checklists;
- home-maintenance packs;
- course/bundle only if value warrants;
- B2B licensing;
- branded explainers for retailers/manufacturers;
- white-label onboarding/how-to service.

Recommendation must not be commission-driven.

## 9. First 20 episodes

1. Tie a simple necktie knot.
2. Sew a button back on.
3. Iron a shirt without creating new creases.
4. Pick the right screwdriver bit.
5. Use a tape measure correctly.
6. Use a spirit level.
7. Choose a wall plug/anchor conceptually.
8. Unclog a simple sink trap safely.
9. Understand a running toilet.
10. Bleed a radiator where system type permits.
11. Check tire pressure.
12. Read tire sidewall basics.
13. Replace windshield wipers.
14. Check engine oil safely.
15. Jump-start basics with strong model/manual warnings.
16. Reset a tripped breaker and know when not to.
17. Locate common home water shutoff.
18. Use a drill without destroying the screw head.
19. Build a basic home maintenance checklist.
20. What five tools should a first apartment actually have?

## 10. Pilot

Start with tasks that are:
- visually explainable;
- low risk;
- frequently searched;
- international or easy to localize;
- cheap to animate.

Measure:
- search impressions;
- completion;
- saves;
- comments saying task succeeded;
- repeat viewership;
- production time;
- correction rate.

## 11. Anti-copy doctrine

Study:
- user need;
- query language;
- category demand;
- common confusion;
- teaching mechanics.

Do not reproduce:
- another creator's emotional backstory as branding;
- distinctive father persona;
- script language;
- channel identity.

Theia should create its own reason to exist.

## 12. Final laws

> **PRACTICAL CONFIDENCE IS THE PRODUCT. THE CARTOON IS THE DELIVERY SYSTEM.**

> **IF THE VIEWER CANNOT DO THE TASK MORE SAFELY AFTER WATCHING, THE VIDEO FAILED.**

> **WARMTH IS PART OF THE FORMAT; ACCURACY IS PART OF THE CONTRACT.**

## Current house law
A project manifest is declarative and cannot grant execution authority. A project may declare a bounded optimization phenotype (MINIMAL / INTERACTIVE / BALANCED / BATCH / VERIFICATION_HEAVY / GPU_HEAVY) that constrains fan-out and expresses placement/reuse intent without naming hardware or granting capabilities.

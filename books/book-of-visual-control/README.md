# The Book of Visual Control

Visual Control is OTHRYS's visual observation and evidence service. Its first resident edition is deliberately OBSERVE-only.

## Resident law
- A frame is evidence, never authority.
- Every observation identifies node, surface, capture source, timestamp, viewport and image digest.
- Blank, stale, future or structurally invalid observations fail closed.
- Before/after comparison is legal only when the evidence is comparable.
- A visual delta is not proof that an intended action succeeded.
- Talos remains verification/evidence authority.
- Trust Canal remains consequential-action authority.
- Mycelium remains node-routing truth.
- Raw image bytes do not enter resident state.

## Current capability
The resident validates finite observations, classifies freshness/usability, derives deterministic evidence identity, compares before/after observations and creates a non-self-certifying Talos verification candidate.

## Closed gates
Screen capture, streaming, OCR/vision interpretation, mouse/keyboard injection, supervised control and autonomous computer use are not admitted.

## PandaOS rule
Copy Panda's useful control-room experience and low-friction visual clarity. Never copy its backend as V2 truth. LIVE = LEDGER = REPLAY = CANVAS remains the standard.

## Current house law
The OBSERVE resident is evidence-bound and non-authoritative. It may describe finite visual facts and deltas; it grants no authority and never claims execution success. Any future capture or control adapter must remain outside this pure kernel and pass a new admission gate.

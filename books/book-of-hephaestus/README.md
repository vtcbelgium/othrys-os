## Forge law — V2-011K training foundation
Hephaestus is a forge system, not a single model. A Forge knows many smiths, their task specialties, inference profiles, cost/locality, measured fitness and qualification state. Ranking never grants execution permission.

The hot path is role-based: FAST LOCAL for atomic currency, HEAVY LOCAL for hard repository work, FREE REMOTE for frontier escalation, and PAID ESCALATION only behind operator approval. Per-model inference controls are mandatory where evidence requires them; Level-1 proved that trivial Qwen3 work should disable thinking so reasoning does not consume the response budget.

Mycelium supplies truthful node capacity, metabolic mode, workload knee and placement pressure; it may recommend PACK/SPREAD placement but may not select semantic authority or certify a builder. Switchyard enforces legal/provider/cost/privacy constraints. Talos independently verifies produced work. Mnemosyne retains builder fitness and failure lessons. Proven stock is reused before generation.

A builder progresses through catalogue/installed -> spark-tested -> qualifying -> qualified/certified -> preferred only through evidence. Catalogue presence, model reputation or benchmark claims never count as OTHRYS qualification.

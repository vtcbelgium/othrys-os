## Extraction priority heuristic
1. Broad reuse across many product families.
2. Small enough boundary that host glue can remain host glue.
3. Existing real caller(s), not hypothetical code.
4. Deterministic or independently verifiable behavior.
5. Security/privacy burden understood.
6. Second consumer can be produced cheaply to prove portability.
7. Extraction reduces duplicate code rather than creating a framework tax.

Initial next-candidate band: notification/alert engine; search/filter contract; user upload/storage adapter; event/calendar view; PDF/report export; SEO render/sitemap pair; usage metering; moderation/report queue. Messaging, wallets, auth and full forums are valuable but higher-gravity and should come later.

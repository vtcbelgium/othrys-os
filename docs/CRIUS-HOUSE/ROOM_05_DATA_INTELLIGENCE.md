# ROOM 05 — DATA & INTELLIGENCE ASSETS

Mission: identify, protect, compound, and commercialize OTHRYS-generated intelligence without violating privacy, confidentiality, licences, or trust.

## Asset classes

### Controlled experimental data
Produced by OTHRYS against tasks/data OTHRYS is allowed to use:
- model benchmark outcomes
- agent completion rates
- latency/cost histories
- regression histories
- repair success/failure
- tool qualification results
- routing performance
- reliability histories
- test/eval outcomes

### Operational meta-data
Potentially valuable only after rights/privacy review:
- aggregate error classes
- aggregate workload categories
- capacity curves
- feature usage patterns
- support categories

Raw user content is not automatically an asset CRIUS may commercialize.

### Curated knowledge assets
- vendor change histories
- pricing histories
- model capability maps
- ecosystem taxonomies
- tool trust registries
- failure taxonomies
- migration knowledge
- domain evaluation packs

## Product forms

- paid benchmark report

## Data moat rules

1. Provenance is mandatory.
2. Rights are mandatory.
3. Raw secrets never become product inventory.
4. De-identification must be real, not cosmetic.
5. Derived statistics should be tested for re-identification risk where relevant.
6. User trust outranks theoretical resale value.
7. Public benchmark methodology must be reproducible enough to deserve trust.
8. Sponsored entities cannot buy a better measured result.
9. Dataset freshness must be visible.
10. A dataset that cannot explain its source or collection conditions is low-trust stock.

## Questions for every dataset

- Who owns the source data?
- Under what licence/terms was it produced?
- Can it legally be redistributed?
- Can only derived statistics be shared?
- Can individuals or customers be inferred?
- Does the dataset remain useful if stripped of sensitive material?
- Is it expensive for competitors to recreate?
- Does it improve another OTHRYS product even if never sold directly?
- What ongoing collection cost exists?
- What evidence proves quality?

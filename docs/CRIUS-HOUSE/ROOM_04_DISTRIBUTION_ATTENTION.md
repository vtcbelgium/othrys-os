# ROOM 04 — DISTRIBUTION & ATTENTION

Mission: treat distribution as an engineered system, not a late marketing task.

## Core thesis

A product with no path to discovery is not commercially mature. CRIUS therefore scores not only product value but **distribution fit**.

## Tiny-tool fishing fleet

OTHRYS should eventually be able to produce many narrow utilities cheaply. CRIUS watches them as low-cost distribution probes.

Desired pattern:
`PAIN QUERY -> TINY USEFUL TOOL -> ORGANIC DISCOVERY -> MEASURE -> KEEP / KILL / EXPAND`

Candidate tool families:
- AI cost calculators
- model/task recommenders
- repo health quick scan
- README vs reality checker
- prompt/token estimators
- migration readiness checker
- collection valuation worksheet
- study workload planner
- transcript-to-flashcard utility
- automation opportunity estimator
- API pricing comparer
- local model hardware fit checker

## Attention quality

CRIUS must distinguish:
- human vs bot traffic
- useful intent vs curiosity
- repeat visitors vs one-off spike
- target user vs irrelevant audience
- content popularity vs product activation

## Distribution score

`INTENT + ORGANICITY + REPEATABILITY + SHAREABILITY + CHANNEL_FIT + LOW_CAC + OWNED_AUDIENCE - PLATFORM_DEPENDENCE`

## Anti-patterns

Reject:
- mass spam
- fake engagement
- review manipulation
- hidden advertorials
- SEO pages with no user value
- forced sharing
- dark-pattern referrals
- scraping/contact harvesting against terms or law

The objective is compounding discovery, not temporary noise.

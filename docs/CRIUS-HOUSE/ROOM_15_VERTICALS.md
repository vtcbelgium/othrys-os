# ROOM 15 — VERTICAL OPPORTUNITY LAB

Mission: repeatedly test whether OTHRYS horizontal capabilities become more valuable when packaged for a narrow domain.

## Why verticalization matters

Generic AI tooling is crowded. Domain packaging can create clearer pain, easier messaging, higher willingness to pay, better evals, and more defensible workflows.

## Vertical test

For each horizontal OTHRYS capability, CRIUS asks:
1. Which domain feels this pain most acutely?
2. Which domain has budget?
3. Which domain has data/evaluation requirements that create a moat?
4. Which domain can OTHRYS credibly dogfood?
5. Which domain creates unacceptable regulatory/support burden?

A vertical is promoted only if the narrowing increases expected value more than it increases complexity.

# ROOM 07 — MEDIA, AFFILIATE & SPONSORSHIP

Mission: monetize attention without corrupting trust.

## Candidate surfaces

- Prometheus newsletter
- Tool Olympics public benchmark pages
- AI model/provider comparison pages
- Study Buddy resource recommendations
- Collector OS marketplace/resource recommendations
- technical guides
- niche directories
- vendor-watch reports
- hardware/model fit guides
- migration/tooling guides

## Revenue mechanisms

### Affiliate
- developer tools
- hosting
- AI providers where programs exist
- books/courses
- learning hardware
- collection marketplaces
- productivity tools

Rules:
- disclose relationship
- never rank solely by payout
- include non-affiliate candidates when better
- verify price/features before claims
- separate recommendation score from commission value

### Sponsorship
Possible packages:
- newsletter sponsor
- benchmark category sponsor
- report sponsor
- event/challenge sponsor
- dataset sponsor
- educational series sponsor

Sponsor may buy visibility, not verdict.

### Advertising
Ads are lowest-priority when they damage UX or require too much tracking. Consider only when:
- traffic is substantial
- user intent tolerates ads
- economics are meaningful
- privacy/consent burden is understood
- ads do not overwhelm the product

### Vendor directory
A verified directory can have:
- free basic listing
- paid enhanced profile
- clearly marked sponsored placement
- verification fee
- enterprise shortlist service

Never sell technical trust badges without independent qualification.

### Jobs / opportunities
If Prometheus or an AI/dev audience becomes meaningful:
- job board
- sponsored hiring post
- training/provider listings
- events

Requires relevance and clear commercial labeling.

## Editorial firewall

Maintain separate fields:
- `EDITORIAL_SCORE`
- `COMMERCIAL_RELATIONSHIP`
- `PAYOUT`
- `SPONSOR_STATUS`

Commercial relationship may be visible to the user and CRIUS, but must not secretly alter evidence scores.

## Media flywheel

`OTHRYS TESTS -> ORIGINAL DATA -> USEFUL PUBLIC CONTENT -> SEARCH/SHARING -> AUDIENCE -> NEWSLETTER -> COMMERCIAL OPTIONS -> FUNDS MORE TESTING`

The flywheel is strongest when content is a byproduct of work OTHRYS already needed to perform.

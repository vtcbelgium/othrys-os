# ROOM 03 — PORTFOLIO DISCOVERY

Mission: continuously scan the OTHRYS estate for assets that may deserve commercial investigation.

## Signals of hidden value

### Demand signals
- repeated user requests
- repeat usage
- strong retention
- organic discovery
- unsolicited sharing
- businesses asking for access
- users asking whether a paid version exists
- manual workflows repeatedly requested as favors

### Pain signals
- people spend hours doing something OTHRYS does in minutes
- expensive consultants solve the same class of problem
- a task is boring, recurring, measurable and error-prone
- users currently stitch together several tools
- users tolerate bad incumbent UX because the job is necessary

### Scarcity signals
- OTHRYS has benchmark history others do not
- OTHRYS has accumulated failure/recovery evidence
- a dataset is expensive to recreate
- a workflow combines several hard integrations
- trust/provenance is difficult for competitors to reproduce

### Internal repetition signals
- same script used across projects
- same manual report built repeatedly
- same verification ritual repeated
- same debugging/harvest workflow reused
- same integration pattern copied multiple times

Repeated internal work is a candidate product factory signal.

## Portfolio review lenses

Every asset is reviewed through at least these questions:
1. Could an individual pay for it?
2. Could a business pay for it?
3. Could someone else pay so the user gets it free?
4. Could it generate qualified leads?
5. Could it create affiliate/referral revenue?
6. Could it be licensed?
7. Could its data/history be sold as intelligence?
8. Could it become a benchmark/certification?
9. Could it be white-labelled?
10. Could it reduce cost elsewhere enough to justify shared savings?
11. Could it act as distribution for another product?
12. Could it strengthen OTHRYS's moat even with zero direct revenue?

## Discovery rule

CRIUS should actively look for **second-order products**.

Example:
`Builder Arena` creates benchmark data.
The benchmark data creates articles.
Articles create search traffic.
Traffic creates newsletter subscribers.
Subscribers create sponsor/affiliate potential.
The dataset creates a paid API.
The evaluation method creates a certification product.
The same machinery creates enterprise private benchmarks.

A single capability can therefore generate a product constellation.

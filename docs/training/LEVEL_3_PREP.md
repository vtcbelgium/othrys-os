## Level 3 purpose

Level 3 moves from isolated primitives and durable local state to **complete bounded applications**. A job must produce a usable application surface, not just a library function. The curriculum remains intentionally below Level 4: external authentication, remote databases, email delivery, remote API dependencies, paid providers, secrets and production deployment are outside the level.

The central law is: **compose proven stock before inventing new capability**. Every job starts with a stock preflight against Level 1/2 training currency, admitted Blocks, proven patterns and current repository code. New capability is justified only when the declared application contract cannot be satisfied safely by existing stock.
## Application gate

Every Level 3 job must pass: stock preflight, declared app contract, bounded workspace/package scope, deterministic core tests, application-visible proof, failure-state preservation, independent Talos verdict, learning receipt and final disposition. Visual jobs additionally require responsive proof plus keyboard/accessibility smoke. Extension jobs additionally require MV3, minimum permissions and no remote code.

A worker `ok:true` never completes a Level 3 job. Hephaestus may select only builders whose Forge roster has `executionAllowed=true`; qualification-queue models cannot be routed. Talos owns the final application verdict. Repair exhaustion, no-op mutation, scope escape and operator recovery remain explicit learning evidence.

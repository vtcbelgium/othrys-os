## Migration rule
`TEMP_LIBRARY.md` remains a historical bootstrap map until every listed item has an explicit canonical owner. Migration is reference-first: never duplicate bytes just to satisfy the metaphor.

## Lifecycle
`CAPTURE -> CLASSIFY -> QUARANTINE/REVIEW -> ADMIT | GARDEN | R&D | HALL_OF_ECHOES`

Admission changes retrieval/currentness; it does not rewrite source evidence. Deprecation moves currentness, never history. Garden/R&D promotion requires an explicit later mission and proof.

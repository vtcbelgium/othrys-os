# V2-010G — House Manager Plan

**Mode:** CONSOLIDATE / TEST / LOG / RESEARCH. No capability expansion.
**Horizon:** one long housekeeping session, divided into bounded gates rather than parallel mutation.

## North star

The house must stay small enough to understand, strict enough to resist drift, and rich enough that old evidence and useful stock are retrievable without becoming current authority.

8. **Closeout:** independent verification, Chronicle/Book/state update, exact diff review, fast-forward sync, next legal action.

## Stop rules
A new idea goes to Garden/R&D unless it fixes a measured housekeeping defect. A historical implementation never becomes a resident by being copied. Security claims require evidence. No new database, model dependency, agent, Titan, service, or UI is admitted in this round.

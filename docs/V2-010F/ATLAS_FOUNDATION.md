# V2-010F — Atlas cognitive graph foundation

## Decision

OTHRYS OS keeps the names already owned by the repository instead of inventing a parallel mythology.

- **Mnemosyne** remains the knowledge authority and institutional-memory Titan.
- **Atlas** remains a derived system/workspace: a read model and visual map, never a Titan and never canonical authority.
- **The Nine Muses** remain semantic gates over one Mnemosyne knowledge store. They are not agents, Titans or databases.
- **Callimachus** remains the existing Mnemosyne review/curation stock to quarry in a later promotion/reconciliation mission.

This mission ports proven constitutional ideas from the earlier Core Atlas/Mnemosyne stock into the current V2 OTHRYS OS house rather than starting a new graph architecture.

## Overlap decisions

The repository already assigns several ideas that had been brainstormed under new names:

- failure / incident / contradiction / scar knowledge → **Melpomene**;
- chronology / revisions / institutional history → **Clio**;
- relationships / dependencies / graph cross-pollination → **Erato**;
- success / reusable patterns / proven capability → **Thalia**;
- research / measurement / external evidence → **Urania**;
- architecture / canon / specifications → **Calliope**.

A new `Chronos` memory subsystem would overlap Clio, and a new `Scars` subsystem would overlap Melpomene. Those names are therefore not introduced here. The OTHRYS originality belongs in mechanics, not redundant mythology.

## Ported foundation

The V2 Atlas now restores the strongest prior Atlas laws:

- typed, stable graph nodes and directed relations;
- explicit provenance on evidence-basis nodes and edges;
- evidence and inference are distinct;
- browser-facing graph data is secret-scanned;
- the graph grants no authority and exposes no mutation API;
- the graph is derived from V2/Mnemosyne evidence rather than becoming a second registry;
- deterministic graph digest when source evidence is unchanged;
- historical V2 result shapes require actual passing proof rather than a filename or evidence pointer alone.

The first projection derives project, systems, Titans, capabilities, models, integrations, declared knowledge, missions, durable Work and Mnemosyne Inbox/Review state.

## OTHRYS cognitive signals

Two non-authoritative signals are added to the old graph foundation:

- **Gravity**: importance/mass derived from truth class, evidence, reuse, connectivity, recency and consequence.
- **Heat**: current activity/freshness signal; active Work can become visually hot without becoming more true.

These values affect presentation and future retrieval policy only. They never promote knowledge or grant execution authority.

## Workstation foundation

`/atlas.html` is now a first-class room in the OTHRYS OS workstation. It is intentionally framework-free and dependency-free for the first cut.

Structure:

`OTHRYS rail → Atlas lifecycle navigation → typed/Muse tree → infinite Canvas graph → knowledge evidence inspector`

The graph supports deterministic clustered layout, pan, zoom, search, Overview/Topics/Work/Evidence lenses, gravity-sized nodes, heat halos, provenance inspection and relation inspection. Inbox and Review are separate lifecycle queues backed by real Mnemosyne records.

The page consumes only authenticated `GET /api/atlas`; there is no Atlas write endpoint.

# V2-010S Preflight — Rhizomorph / Experience / Sparse Resilience

**Great Harvest disposition:** ADAPT.

Historic 061D already defines COLD/CANDIDATE/WARM/REINFORCED/STALE/RETIRED lifecycle, correctness gates, calibration confidence, failure/retry ceilings and deterministic decay. Historic 061H strengthens this with predeclared route families, immutable observations, holdout maturity, Pareto frontiers, hysteresis, degrade/retire/quarantine states and the explicit law: preference may learn which **legal** route works best but may never learn what is legal.

Current V2 now has the prerequisites the old system did not: project phenotypes, measured metabolism, WorkKey, compatibility-gated Anastomosis, Context Metabolism and verified Artifact reuse. 010S should therefore be smaller than the old 1,200–1,500 line subsystem.

First slice: define immutable flow observations and a deterministic qualifier over a finite route family. Reinforcement requires correctness + integrity + authorityOk, minimum evidence, an explicit holdout pass and non-dominance on a transparent objective vector. Preference is derived/disposable. A changed route version, environment, contract or authority envelope invalidates preference to fallback; frequency alone cannot promote.

Second slice only after qualification proof: sparse resilience budget. Permit bounded cross-links among already-legal routes and require every reinforced link to expose decay/retraction conditions. No topology explosion, route generation, hidden learning state or background daemon.

PandaOS contributes only presentation: later the Work/Progress surface should be able to say why a route became preferred, degraded or fell back. Native OTHRYS evidence remains canonical.

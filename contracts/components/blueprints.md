# Component Contract: The Book of Blueprints

**ID:** `blueprints`
**Book:** `books/book-of-blueprints/README.md`
**Owner:** `GPT_CONTROL`
**Purpose:** Single canonical desired-state product contract for one Oros.
**Inputs:** product objective; capability outcomes; constraints; reuse policy; eligible ranges/gaps
**Outputs:** provider-neutral desired capability map for Factory resolution
**Dependencies:** Oros identity; Block doctrine; Factory; Trust/Talos constraints
**Allowed touch:** Blueprint documents and governed projections under mission scope
**Forbidden touch:** grant authority; promote Blocks; bind secret values; claim runtime truth; create a second Blueprint truth
**Authority:** NO_SELF_GRANT -- Blueprint requests and constrains, never executes
**Evidence:** docs/architecture/OTHRYS_HIERARCHY.md; docs/architecture/OFFICIAL_BLOCK_OROS_CONSTELLATION_MODEL.md; harvested Block Composition Law

## Loop contract
- OWNER: `GPT_CONTROL`
- TRIGGER: explicit Oros design/change mission
- INPUT: current Oros evidence + desired outcomes + constraints
- STATE: exactly one canonical Blueprint revision
- BUDGET: bounded design/reconciliation pass
- EXIT CONDITION: desired state is explicit or a gap/conflict is recorded
- EVIDENCE: Blueprint revision + reconciliation proof
- STALL/FAILURE: ambiguous product truth or unauthorized capability change fails closed

# BOOK OF ORACLE

**Hyperion Arm of Signal Interpretation, Winner Detection, and Reality Reading**

Oracle reads what happened after reality touched an OTHRYS asset. It does not predict mystically; it interprets evidence.

> **TRAFFIC IS WEATHER. BEHAVIOR IS CLIMATE.**

## 1. Mission
`TELEMETRY -> CONTEXT -> SIGNAL -> ANOMALY CHECK -> PATTERN -> VERDICT -> NEXT ACTION`

## 2. Verdicts
`INSUFFICIENT_DATA`, `NO_SIGNAL`, `RETEST`, `ITERATE`, `PROMISING`, `WINNER`, `BREAKOUT`, `DEGRADING`, `SUSPEND`.

## 3. Product Signals
Activation, value completion, repeat use, retention, organic acquisition, support burden, failure rate, cost, requests, accumulated history/data value, workflow dependency and legitimate commercial intent.

## 4. Media Signals
Theia returns media evidence such as first-seconds retention, completion, average duration, rewatch, save/share, returning viewers, episode-to-episode return, search persistence, meaningful questions, character/IP affinity and production burden.

Oracle interprets those signals for **economic/portfolio meaning**:
- is demand repeatable?
- is the production burden justified?
- does the property deserve more oxygen?
- is there owned-asset/IP optionality?
- is the signal strong enough to test monetization or scale?

Oracle does not rewrite Theia's format genome or character bible merely because a metric moved.

## 5. Signal Ladder
`IMPRESSION -> ATTENTION -> COMPLETION -> RETURN -> SHARE/SAVE -> SEEK MORE -> DEPEND -> REQUEST/PAY`
Different assets may terminate at different valuable rungs.

## 6. Context
Compare like with like. A 30-second children's Short and a developer benchmark need different contracts. Normalize by format, age, acquisition source, maturity and cost where possible.

## 7. Anomalies
Bot traffic, one external mention, seasonal spikes, algorithmic bursts, measurement changes and outages can distort interpretation. Flag rather than romanticize anomalies.

## 8. Winner Standard
A winner normally requires repeatability across artifacts/cohorts/time or unusually strong evidence with a plausible mechanism. Oracle explains why it believes the signal exists.

## 9. Feedback
Verdicts feed Prospector, Laboratory, Distributor, Magnifier and Portfolio. Media-relevant verdicts return to **Theia through the sibling contract** as economic evidence, not direct edits to Story Forge or production state. Mnemosyne preserves historical interpretation so later evidence can prove Oracle wrong.

## 10. Laws
> **TRAFFIC IS WEATHER. BEHAVIOR IS CLIMATE.**

> **POPULARITY IS A SIGNAL, NEVER A PERMISSION.**

> **A WINNER IS A PATTERN WE CAN EXPLAIN AND REPEAT.**

> **ORACLE MAY BE WRONG; ITS EVIDENCE MUST BE INSPECTABLE.**

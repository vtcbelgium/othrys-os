# BOOK OF MEDIA FACTORY

**Hyperion Arm of Media Production, Packaging, and Derivative Manufacturing**

Media Factory converts approved research, stories and product knowledge into finished native media artifacts. Story Forge decides narrative structure; Media Factory manufactures the artifact.

> **ONE CANONICAL IDEA. MANY NATIVE FORMS. ZERO EXCUSE FOR SLOP.**

## 1. Mission
`SOURCE OBJECT -> FORMAT CONTRACT -> STORY/SCRIPT INPUT -> SCENE PLAN -> ASSETS -> ASSEMBLY -> QA -> PLATFORM PACKAGE -> HANDOFF`

## 2. Canonical Source
Every derivative points to canonical research/story/product evidence. Shorts, long video, article, carousel, quiz and printable may share truth while using different pacing and composition.

## 3. Production Blocks
Storyboard/shot planner; asset router; illustration/animation; voice; music/SFX rights; editor/assembler; subtitles; localization; thumbnail/title lab; metadata packager; provenance ledger; renderer; quality gate.

## 4. Native Format Law
Do not blindly resize. A Short needs immediate compression; long-form needs breathing room; a carousel needs visual sequence; children's media needs age-appropriate density; technical media needs inspectable evidence.

## 5. Production Contract
Declare format, audience, duration, aspect, source version, story version, visual identity, voice, factual sensitivity, rights, target quality, cost budget and review level.

## 6. Asset Provenance
Track generated/commissioned/licensed assets, model/tool, source material, music, fonts, voice rights and transformations where material. Unknown rights fail closed for publication.

## 7. Quality Gates
Factual accuracy; continuity; broken frames; visual artifacts; audio intelligibility; sync; subtitles; spelling; age suitability; rights; disclosure; repetitive content; metadata; CTA/link validity.

## 8. Production Economics
Measure research handoff friction, asset cost, render cost, human review, rework, time/finished minute, localization cost and derivative marginal cost. Seek minimum sufficient quality, then invest more only when evidence justifies it.

## 9. Template Intelligence
Templates preserve useful production mechanics without making every artifact identical. Version templates and record which properties use them.

## 10. Autonomy
`DRAFT -> HUMAN_APPROVAL -> APPROVED_LOW_RISK_TEMPLATE -> BOUNDED_AUTO_PRODUCTION -> EXCEPTION_REVIEW`
Publication authority remains separately governed.

## 11. Anti-Slop
Reject generic voice+stock filler, random visual changes, factual footage mismatches, copied creator aesthetics, low-quality translation, repetitive mass output and artifacts whose production trick is more interesting than their value.

## 12. Laws
> **ONE CANONICAL IDEA. MANY NATIVE FORMS.**

> **THE CALENDAR DOES NOT OUTRANK THE QUALITY GATE.**

> **AUTOMATION SHOULD LOWER THE COST OF CARE, NOT REMOVE CARE.**

## 13. Scripted Animation Production Profile

Animation is a specialized Media Factory profile, not a separate factory.

The reference property is `hyperion/media/BOOK_OF_PEMBERTON.md`.

For scripted animation, the preferred pipeline is:

`SCRIPT LOCK -> STORYBOARD -> SCRATCH AUDIO -> ANIMATIC -> ANIMATIC LOCK -> FINAL PERFORMANCE -> LAYOUT -> ASSET PREP -> ANIMATION -> COMPOSITE -> SOUND/MUSIC -> EDIT -> MASTER REVIEW -> MASTER LOCK -> PACKAGING`

The expensive stages start only after the story works in timed form.

> **SPEND INTELLIGENCE BEFORE COMPUTE.**

### 13.1 Animatic Gate

The animatic is the first timed movie.

It should combine:
- storyboard frames;
- real shot durations;
- scratch dialogue/narration;
- temporary SFX/music;
- rough camera motion;
- transitions.

Review it for:
- comprehension without explanation;
- opening strength;
- character behavior;
- geography;
- pacing;
- midpoint change;
- payoff;
- ending;
- runtime.

A weak animatic is repaired before expensive rendering.

### 13.2 Structured Shot Record

A storyboard/shot should be represented as data as well as imagery.

Suggested fields:

```text
episode_id
scene_id
beat_id
shot_id
start_time
duration
story_function
attention_function
comedy_function
location
characters
props
camera
framing
movement
pose_start
pose_end
expression
action
dialogue
vocalization
sfx
music
child_read
adult_read
gag_id
arc_id
continuity_in
continuity_out
asset_dependencies
source_references
rights_state
generation_receipt
review_state
```

This makes continuity, dependencies, QA and analytics addressable without treating an image folder as production state.

### 13.3 Attention Map

Do not confuse attention design with frantic editing.

For family animation, testable production heuristics may include:
- a readable visual question in the opening seconds;
- clear immediate problem by roughly the first 30 seconds;
- meaningful perceptual change approximately every 6–12 seconds where appropriate;
- clue, obstacle, payoff, joke or answer approximately every 25–40 seconds;
- material story-state change approximately every 60–90 seconds.

These are hypotheses to test against real audience data, not universal cognitive laws.

### 13.4 Storyboard Lint

A property may define property-specific lint rules before animatic lock.

Generic checks include:
- hook absent;
- objective unclear;
- long visual inactivity without purpose;
- contradictory continuity;
- unexplained prop;
- asset/version mismatch;
- repeated running gag with no variation;
- adult layer obscuring child comprehension;
- unknown-rights dependency;
- scene exists only to fill runtime.

### 13.5 Asset Reuse Law

Reuse rigs, locations, effects, camera setups and recurring behavior.

Do not reuse plots by changing nouns.

Production reuse lowers cost.

Narrative reuse without variation creates slop.

### 13.6 Episode Derivative Bundle

A long-form episode may deliberately produce:
- main episode;
- hook Short;
- character Short;
- cute/emotional Short;
- story/lore Short;
- still pack;
- native vertical recompositions;
- several truthful title candidates;
- several materially different thumbnail candidates;
- subtitle master;
- dub-ready audio separation where practical;
- provenance package.

A Short is a designed artifact, not automatically a random excerpt.

### 13.7 Analytics Back-Mapping

Because storyboard shots have timestamps and IDs, post-release signals may be mapped to:
- scene;
- beat;
- shot;
- gag;
- character behavior;
- runtime segment;
- packaging version.

Keep **observation**, **hypothesis**, **test**, and **result** separate.

One retention dip does not become permanent creative law.

## 14. Reference Animation Property

Pemberton is the current detailed animation reference because it stresses:
- persistent character identity;
- recurring locations;
- season continuity;
- transformable recurring transport;
- child/adult double-layer comedy;
- Shorts and long-form packaging;
- property memory;
- rights boundaries;
- shot-level analytics.

Its property-specific rules remain in `hyperion/media/BOOK_OF_PEMBERTON.md`; generic reusable production law remains here.

> **THE PROPERTY SPECIALIZES THE FACTORY. THE PROPERTY DOES NOT BECOME THE FACTORY.**

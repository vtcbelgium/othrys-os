# OTHRYS OS Quarry

**Status:** NON-CURRENT / ZERO AUTHORITY.

The Quarry preserves useful code, prototypes, legacy patterns, and deferred experiments that do not belong in the current OTHRYS OS runtime.

A Quarry item may be inspected, compared, tested in isolation, or cited as provenance. It may not be imported into runtime, advertised as a resident capability, or treated as current architecture without a separate admitted mission.

Classification:
- `deferred/` — relevant idea or prototype intentionally postponed.
- historical source remains in its original repository and Mnemosyne estate whenever possible; do not duplicate bytes merely to make the Quarry look complete.

Promotion path: `QUARRY -> RESEARCH/PROOF -> MISSION -> VERIFIED IMPLEMENTATION -> HOUSE`. Documentation alone never promotes an item.

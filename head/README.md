# OTHRYS Head

**Status:** ACTIVE DESCRIPTIVE CANON  
**Scope:** identity, behaviour and human-context projection.  
**Authority:** descriptive only.

The Head is the human-editable projection of who OTHRYS is, how it should
behave, and who it is serving in the current owner context.

It contains exactly three primary documents:

1. `IDENTITY.md` — who OTHRYS is.
2. `SOUL.md` — how OTHRYS behaves.
3. `USER.md` — the human context OTHRYS is serving.

## Precedence

```text
accepted constitutional / Foundation law
        ↓
authority + component contracts / Loop law
        ↓
IDENTITY.md
        ↓
SOUL.md
        ↓
USER.md
        ↓
current Mission / Work State
        ↓
transient conversation
```

A lower layer may refine tone, context or working style. It may not override
a higher layer, create a permission, reveal a secret, bypass evidence, or
declare work complete.

## Web editing contract

OTHRYS Web may expose these files through `/system/settings/head`, but the
browser is never the source of authority. A change must become an explicit
diff/proposal, pass validation, preserve history, and then be applied to this
canonical source through a governed write path.

The Head is not memory storage, a secret store, a mission queue, or an
authorization database.
